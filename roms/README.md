# Juegos

Esta carpeta va vacía a propósito: **tiki_emu no distribuye ROMs ni BIOS**. Lo que pongas aquí es
cosa tuya y tu responsabilidad.

## Cómo añadir juegos

**En el móvil host**, lo cómodo es no tocar esta carpeta: conecta el móvil por USB y arrastra los
ficheros a `Almacenamiento interno → Roms`.

- Con **la app de Android**, esa carpeta se le indica una vez desde el lobby, con «Carpeta de
  juegos». Queda recordada.
- Con **Termux**, se lee sola, siempre que hayas ejecutado `termux-setup-storage` una vez.

**En un PC**, o si prefieres tenerlos con el proyecto, déjalos aquí. Sueltos o en subcarpetas, da
igual.

El sistema se deduce de la extensión —`.nes`, `.sfc`, `.smc`, `.gb`, `.gbc`, `.gba`, `.md`— y en los
`.zip`, del nombre de la carpeta que los contiene: `roms/snes/loquesea.zip`.

## Para probar sin nada tuyo

Hay homebrew de licencia libre con la que probar la consola. Dos que funcionan bien:

- **Alter Ego**, de Shiru — plataformas de NES, con salto: sirve para comprobar de un vistazo que el
  mando responde. Es *freeware*, no dominio público.
- **Lan Master**, del mismo autor — puzzle, de dominio público.

Ambas en <https://shiru.untergrund.net>, sección Software.
